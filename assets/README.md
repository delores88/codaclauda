# Original ClaudaCoda artwork

The two interlocking C/chat glyphs in `brand.svg` were drawn specifically for
ClaudaCoda. `scripts/artwork.py` generates the PNG and Windows ICO variants with
Pillow, along with an illustrative 1600 × 900 Marketplace thumbnail. These are
first-party MIT artwork. They contain no copied provider logos or stock assets.

`marketplace-thumbnail.png` is promotional illustration, **not** an application
screenshot or proof of a completed workflow. Marketplace screenshots must be
captured separately from the actual installed application with real state.

The script uses the installed Windows Segoe UI font for rendered promotional
text; no font file is bundled or redistributed. Runtime UI uses system fonts.
