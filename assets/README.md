# Original CodaClauda artwork

The interlocking C/chat glyphs are first-party MIT artwork. The existing
scripts/artwork.py source renders the icon and 1600 x 900 illustrative thumbnail;
no provider logos or stock images are copied. Promotional text uses the installed
Windows Segoe UI font. No font file is bundled or redistributed.

The thumbnail is an illustration, not an application screenshot.

marketplace-screenshot.png shows the actual CodaClauda 0.3.0 Message board running
from an isolated, byte-identical copy of the verified installed GUI and CLI from
source e84b74b4ec9d0a11b7ba8a6a306dc3e11a48e2ed. Its Demo Notebook conversation,
agent labels and owner are synthetic sample data. No provider session was
started; activity labels are application heuristics, not verified model work.
The capture was converted from the native tool's JPEG encoding to PNG without
changing decoded pixels, cropping or retouching.

The screenshot demonstrates rendering and local mailbox display. Actual in-place
installation and preservation of the owner's existing board were verified
separately. marketplace-screenshot-receipt.json records the exact source,
installer/payload hashes and capture boundary without private host paths or data.

This artwork commit is separate from the immutable application source commit;
creating release artwork does not rebuild or change the reviewed installer.
